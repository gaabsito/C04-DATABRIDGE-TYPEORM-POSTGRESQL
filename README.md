# C04 · DataBridge · TypeORM y PostgreSQL

Ejercicios de React Native con Expo, NestJS, TypeORM y PostgreSQL.

## Ejercicio 01 · Game Vault

Colección de videojuegos persistida en PostgreSQL. Incluye el reto de añadir el campo `genero` en la Entity, la base de datos, la respuesta JSON y las tarjetas del móvil.

Consulta [las instrucciones del ejercicio](EJERCICIO-01/README.md) y [las comprobaciones realizadas](EJERCICIO-01/VERIFICACION.md).

## Ejercicio 02 · CineBox

Colección de películas con `repository.find()` y el campo persistente `favorita`, representado con ♥ / ♡. Consulta [las instrucciones](EJERCICIO-02/README.md).

## Ejercicio 03 · Pet Profile

Consulta individual con Path Param, `findOneBy()` y nivel de energía persistente. Consulta [las instrucciones](EJERCICIO-03/README.md).

## Ejercicio 04 · Food Spots

Creación con POST, Body, DTO, create/save y precio medio persistente. Consulta [las instrucciones](EJERCICIO-04/README.md).
